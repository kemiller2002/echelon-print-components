# Tutela Security Evidence Record

Folio MUST support a standard printable/shareable Tutela Security Evidence Record.

Required sections: release posture and immutable identity; scope/limitations; blockers; invariant matrix; threats/findings; unknown security effects; stale evidence; exceptions with expiry; evidence index/provenance; methodology; assessment time.

Requirements:
- Never describe PASS as proof that a system is secure.
- Preserve stable Tutela IDs and evidence references.
- Unknowns and limitations MUST be prominent and printable.
- Sensitive evidence MUST be redacted by default.
- Status MUST not depend on color.
- Page headers/footers MUST identify subject ref and assessment identity.
- Long evidence tables MUST repeat accessible headers and avoid clipping.
- Export MUST be deterministic from the same assessment artifact.
- An evidence record MUST identify whether evidence was independently verified.
